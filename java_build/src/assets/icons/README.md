# Icons

Equipment and UI icons. Weapon data points at these through `imageName`.

- `warframe.svg`, `primary.svg`, `secondary.svg`, `melee.svg`: category icons (placeholders, original drawings).
- `excalibur.svg`: Excalibur emblem (placeholder). Replace with the real logo file.

The Arsenal does not load these files yet; it draws its own silhouettes in `drawEquipIcon`.
